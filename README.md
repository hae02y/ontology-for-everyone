# 처음 만나는 온톨로지: AI가 우리 회사의 일을 이해하게 만드는 법

![처음 만나는 온톨로지 책 표지](assets/ontology-book-cover.png)

*표지: 이 책을 위해 생성한 이미지입니다. 본문 도식은 별도의 자체 제작 SVG입니다.*

**출처 확인일: 2026년 11월 4일 · 전 장 원고 완성: 2026년 11월 5일**

기획자와 운영 담당자가 회사의 용어, 데이터, 업무 규칙을 한눈에 설명할 수 있도록 돕는 실무 입문서입니다. 고객지원의 주문·배송·반품이라는 하나의 가상 사례를 따라가며, 마지막에는 독자 자신의 작은 온톨로지 설계표를 완성합니다.

이 책의 목표는 독자가 RDF·OWL 코드를 외우는 것이 아닙니다. 무엇을 같은 대상으로 볼지, 관계의 뜻과 방향은 무엇인지, 어떤 자료를 믿고 어떻게 점검할지 설명할 수 있게 되는 것입니다.
